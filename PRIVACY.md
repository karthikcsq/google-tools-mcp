# Google Tools MCP Privacy Policy

Updated: October 6, 2026

## Access and use

Google Tools MCP accesses Google data only with your authorization. Depending on the permissions granted, this includes files, documents, spreadsheets, presentations, forms, email, calendars and tasks. It uses this data to perform the operations you request through your MCP client.

## Storage and sharing

The server stores OAuth credentials and tokens on the machine running it. Local working copies and logs may also contain data and remain until deleted. Google API requests use HTTPS.

Tool results are returned to your configured MCP client, which may send them to an AI provider or other connected service. Those services have their own privacy policies. Google Tools MCP does not sell your data, use it for advertising, or train AI models.

## Control and deletion

You can revoke access through [Google Account connections](https://myaccount.google.com/connections). Remove stored credentials, tokens, working copies and logs from the server to delete local data. Revoking access does not delete existing copies or data held by your MCP client.

## Google API policy

Google Tools MCP's use and transfer of information received from Google APIs will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements.

## Contact

For questions or deletion requests, contact the operator of your deployment using the support email shown on its Google consent screen.
